# Problem 1 - API Data Retrieval and SQLite

## Objective

Fetch book data from an external REST API, store the retrieved data in a local SQLite database, and display the stored records.

## Assumption

Since the problem statement does not specify a particular API, an appropriate public book API will be used. The program will extract the book title, author, and publication year where available. Missing values will be handled appropriately.

## Technologies

- Python
- REST API
- JSON
- SQLite
- Requests
